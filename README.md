# Manu & Lakshmi — Wedding Reception Invitation Website 💍✨

A modern, vibrant, and interactive wedding invitation website built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

- **Chic Opening Screen with Song**:
  - Warm amber-botanical backdrop with falling golden petals and ambient glow.
  - Couple opening portrait in a modern arched frame.

- **Modern Couple Aesthetic (Zero OM / God Symbols)**:

- **Interactive 3D Wedding Card Opening**:

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌐 Deploying to Vercel

This repository includes [`vercel.json`](./vercel.json) ready for 1-click deployment on Vercel:

1. Push this folder to a GitHub repository.
2. In [Vercel](https://vercel.com), click **Add New Project** and select this repository.
3. Keep default settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**!
